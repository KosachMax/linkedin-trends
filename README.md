# LinkedIn Trends

Daily digest of tech trends and world news, generated by Python and published as a static Astro site on GitHub Pages.

News aggregation runs every day at 08:30, 14:00, and 20:00 Moscow time. Digest profiles currently cover world news, technology, FC Liverpool, and the Russia–Ukraine front.

## Local usage

```bash
pip install -r requirements.txt
cp .env.example .env   # fill in your keys
python main.py         # runs both pipelines, writes to Obsidian vault
python main.py --mode tech   # tech only
python main.py --mode news   # news only
```

### Required env vars (`.env`)

| Variable | Required | Description |
|---|---|---|
| `GOOGLE_API_KEY` | yes | Google AI Studio key (free) — aistudio.google.com/apikey |
| `OBSIDIAN_VAULT_PATH` | locally | Absolute path to your Obsidian inbox folder |
| `GUARDIAN_API_KEY` | optional | The Guardian API key (uses public `test` key if absent) |

## GitHub Setup

1. **Push** this repo to GitHub

2. **Settings → Secrets → Actions** — add secrets:
   - `GOOGLE_API_KEY`
   - `GUARDIAN_API_KEY` (optional)

3. **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: `gh-pages` / folder: `/ (root)`
   - Save

4. **Actions → Aggregate News → Run workflow** — manually collect and aggregate fresh news

5. **Actions → Build & Deploy App → Run workflow** — rebuild only the Astro frontend without running aggregation

6. Site will be at: `https://<username>.github.io/<repo-name>/`

### Site features (Astro)
- Static daily news feeds generated from JSON
- Separate world, tech, FC Liverpool, and Russia–Ukraine front digests
- Expandable event context, history, and sources
- Source-origin labels for international, Ukrainian, Russian, state, official, and independent reporting
- Light and dark themes
- Date archive navigation

## How it works

```
Aggregate News (schedule or manual)
  ├── test Python pipeline
  ├── collect, normalize, deduplicate, and synthesize events
  ├── commit data/digests and data/runs to main
  └── dispatch Build & Deploy App when JSON changed

Build & Deploy App (frontend/data push or manual)
  ├── astro check
  ├── astro build
  └── peaceiris/actions-gh-pages → gh-pages branch
```
## Current architecture

Новая архитектура:

```text
collectors → normalized article pool → digest profiles → AI validation → daily JSON → Astro
```

## Новый стек

- Python package: `src/trends`
- Источники: `config/sources/*.yaml`
- Выпуски: `config/digests/*.yaml`
- Архив: `data/digests/<digest>/days/YYYY/MM/YYYY-MM-DD.json`
- Frontend: `frontend/`
- AI: Gemini Structured Outputs + Pydantic + semantic validation

Для фронтового выпуска материал проходит только при наличии минимум двух независимых источников из минимум двух групп: международной, украинской или российской. Государственные и официальные сообщения сохраняются как атрибутированные заявления стороны; несовместимые версии получают статус `disputed`.

Подробная инструкция: [добавление источников и дайджестов](docs/ADDING_SOURCES_AND_DIGESTS.md).

