Обновления содержат исправления ошибок, улучшения поддержки Python (включая Python 3.13 и 3.14), доработки в работе с Redis, Django и Kafka, а также изменения в документации. Особо отмечается откат использования urllib3 для SQS транспорта в пользу pycurl из-за критических проблем. Минимальная версия Python для Celery 5.6.0 теперь 3.9.

Расширенный контекст

Проект Celery, являющийся распределенной системой очередей задач, регулярно выпускает обновления для улучшения стабильности, производительности и поддержки новых версий Python. В представленных материалах перечислены последние релизы, начиная с версии 5.5.2 и заканчивая 5.6.3. Эти обновления включают в себя как исправления обнаруженных ошибок, так и добавление новых функций или улучшение существующих. Например, были исправлены проблемы с обработкой оставшегося времени при изменении летнего/зимнего времени, рекурсивные ошибки в DjangoWorker, проблемы с аутентификацией Redis Sentinel ACL, а также улучшена поддержка Django Connection pool и Redis Backend с credential_provider. В версии 5.6.0 была повышена минимальная требуемая версия Python до 3.9 и добавлена начальная поддержка Python 3.14. Также было принято решение вернуться к использованию pycurl вместо urllib3 для SQS транспорта из-за выявленных критических проблем.

Регулярные обновления Celery важны для пользователей, так как они устраняют известные ошибки, повышают безопасность и совместимость с новыми версиями Python и другими зависимостями. Пользователи, использующие Celery в своих проектах, должны следить за этими релизами, чтобы своевременно обновляться и избегать потенциальных проблем, связанных с устаревшими версиями. Обновления также могут включать улучшения производительности и новые возможности, которые могут быть полезны для оптимизации работы с очередями задач.
