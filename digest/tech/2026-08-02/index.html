Программное обеспечение · Завершено 7,0

SQLAlchemy выпустила три бета-версии своего основного продукта: 2.1.0b1, 2.1.0b2 и 2.1.0b3. Эти релизы включают в себя ряд улучшений и новых функций, направленных на повышение производительности и удобства использования. Среди ключевых изменений — поддержка свободных потоков Python в колесах PyPI, новые возможности для настройки загрузки отношений, улучшенная обработка опций выполнения для получения объектов и поддержка исключений фреймов в оконных функциях SQL.

Расширенный контекст

В период с января по июнь 2026 года команда разработчиков SQLAlchemy последовательно выпустила три бета-версии своего флагманского продукта под номером 2.1.0. Релиз 2.1.0b1, вышедший 21 января 2026 года, принес поддержку свободных потоков Python в колесах, публикуемых на PyPI, а также оптимизировал работу с зависимостью greenlet для поддержки asyncio. Версия 2.1.0b2, выпущенная 16 апреля 2026 года, представила новые возможности для настройки декларативной базы данных, включая использование миксин-классов, и добавила параметр `_sql.over.exclude` для поддержки исключений фреймов в оконных функциях SQL. Наконец, релиз 2.1.0b3 от 27 июня 2026 года ввел параметр `selectinload.chunksize` для управления загрузкой отношений и обеспечил корректную работу опции `populate_existing` при использовании `Session.get`.

Выпуск бета-версий SQLAlchemy 2.1.0 знаменует собой важный этап в развитии библиотеки, предлагая разработчикам новые инструменты для оптимизации работы с базами данных. Улучшения в управлении отношениями, поддержка современных версий Python и расширенные возможности SQL позволяют создавать более производительные и надежные приложения. Эти обновления важны для всех, кто использует SQLAlchemy для взаимодействия с базами данных, так как они могут привести к существенному повышению эффективности и упрощению разработки сложных систем.

Расширенный контекст

uv — это быстрый менеджер пакетов для Python, написанный на Rust. Он стремится заменить pip и setuptools, предлагая более высокую производительность и улучшенную обработку зависимостей. Регулярные выпуски новых версий свидетельствуют о активной разработке и стремлении улучшить функциональность и стабильность инструмента. Обновления включают как исправления ошибок и улучшения производительности, так и новые функции, такие как поддержка различных версий Python, улучшенная обработка lock-файлов и новые возможности для проверки пакетов. Особое внимание уделяется безопасности, включая обновление библиотек для обработки ZIP-архивов и добавление проверок на вредоносное ПО.

Регулярные обновления uv важны для разработчиков Python, поскольку они обеспечивают доступ к последним улучшениям производительности, исправлениям ошибок и новым функциям, которые могут упростить управление зависимостями и повысить безопасность проектов. Версия 0.12.0, несмотря на потенциальные нарушения рабочих процессов, направлена на повышение общей надежности и совместимости. Новые функции, такие как поддержка локальных индексов и политики предварительных версий, предоставляют большую гибкость при работе с пакетами. Улучшения в ветке 0.11, включая проверку на вредоносное ПО, способствуют созданию более безопасной экосистемы Python. Разработчикам рекомендуется следить за этими обновлениями и адаптировать свои рабочие процессы для использования преимуществ новых версий.

В руководстве рассматривается проблема запуска торгового программного обеспечения на устройствах Android, связанная с отсутствием поддержки настольных приложений, полноценной среды Python и доступа к данным NSE в реальном времени. Предлагается решение, превращающее Android-устройство в полноценный Linux-терминал с помощью Termux. В сочетании с Python и планировщиком cron, а также источниками данных NSE, это позволяет создать рабочую станцию для алгоритмической торговли. В качестве примера приводится nse_ai_agent — открытый ИИ-ассистент для трейдинга, полностью функционирующий на Termux.

Данное руководство представляет практический подход к созданию доступной платформы для алгоритмической торговли, используя обычный смартфон на Android. Это открывает возможности для индивидуальных инвесторов и трейдеров с ограниченным бюджетом для участия в торговле на фондовом рынке с помощью современных технологий. Возможность развернуть полноценную торговую систему на мобильном устройстве снижает порог входа и делает алгоритмическую торговлю более доступной.
