Расширенный контекст

В период с 15 по 28 июля 2026 года команда разработчиков Astral uv Releases выпустила несколько обновлений для своего пакетного менеджера uv. Версия 0.11.29 добавила поддержку CUDA 13.2 для PyTorch, улучшила вывод JSON для команды uv tree и уточнила сообщения об ошибках при неудовлетворительных диапазонах зависимостей. Версия 0.11.30 внесла поддержку CPython 3.15.0b4 и оптимизировала работу с кэшем, а также ускорила сериализацию lock-файлов. Обновление 0.11.31 добавило возможность ссылаться на члены других рабочих пространств по пути, обновило данные о часовых поясах для Windows и ввело настройку алгоритма хеширования для генерации lock-файлов, а также добавило настройки для проверки на вредоносное ПО. Версия 0.11.32 представила опции --package и --all-packages для команды uv check, позволила обновлять несколько маркеров одного пакета командой uv upgrade и отклонять не канонические lock-файлы. Версия 0.11.33 сфокусировалась на оптимизации производительности, уменьшив размер бинарных файлов uv и используя .tar.gz архивы для установки Pyodide, а также добавила проверку заблокированных инструментов на вредоносное ПО перед повторным использованием кэша.

Эти обновления для пакетного менеджера uv направлены на повышение его функциональности, производительности и безопасности. Поддержка новых версий Python и PyTorch, а также оптимизация работы с lock-файлами и кэшем, делают процесс управления зависимостями более эффективным и надежным для разработчиков. Введение новых настроек безопасности, таких как проверка на вредоносное ПО, повышает уровень защиты проектов от потенциальных угроз. Улучшения в управлении рабочими пространствами и командах проверки пакетов предоставляют разработчикам более гибкие инструменты для работы.
