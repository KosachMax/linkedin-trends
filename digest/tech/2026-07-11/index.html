Python 3.10: Функция zip() получила строгий режим для проверки несоответствия длин

В Python 3.10 была добавлена новая функция в встроенную функцию zip(), которая позволяет избежать молчаливого усечения данных при итерации по нескольким спискам. Ранее zip() останавливалась, как только самый короткий итерируемый объект исчерпывался, что могло привести к потере данных без уведомления. Теперь, с параметром strict=True, zip() будет вызывать исключение ValueError, если входные итерируемые объекты имеют разную длину. Это улучшение помогает разработчикам избегать потенциальных ошибок, связанных с несоответствием размеров данных при параллельной обработке.
