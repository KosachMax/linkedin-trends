Расширенный контекст

В подкасте Йоханнес Шиклингом рассматривает эволюцию архитектуры веб-приложений, отходя от устоявшейся трехзвенной модели (клиент, сервер, база данных). Он представляет локальный подход (local-first), где основная логика и данные обрабатываются на стороне клиента, что позволяет улучшить производительность и отзывчивость приложений. Особое внимание уделяется клиентскому событийному исходному коду, который позволяет отслеживать все изменения данных как последовательность событий. Это обеспечивает полную историю изменений и упрощает синхронизацию данных между устройствами. Шиклингом делится практическим опытом применения этого подхода при разработке музыкального приложения Overtone, где он заменил ORM Prisma на собственное решение, основанное на SQLite и клиентском событийном исходном коде.

Переход к клиентскому событийному исходному коду и локальным подходам может кардинально изменить способ разработки современных веб-приложений. Этот подход обещает повышение производительности за счет обработки данных на стороне клиента, улучшение пользовательского опыта благодаря мгновенной отзывчивости и упрощение синхронизации данных. Для разработчиков это означает необходимость освоения новых паттернов проектирования и инструментов, таких как SQLite на клиенте и понимание принципов работы CRDT. Такой сдвиг может привести к созданию более мощных и гибких приложений, способных работать в условиях нестабильного сетевого подключения, и открывает новые возможности для инноваций в области пользовательских интерфейсов и управления данными.

Представлен новый Web to Markdown/JSON API, который позволяет эффективно преобразовывать веб-страницы в структурированные данные (Markdown или JSON) для обучения больших языковых моделей (LLM). API устраняет необходимость в сложных инструментах, таких как headless-браузеры или парсинг с помощью BeautifulSoup, предлагая простое HTTP-решение. Параллельно анонсирован Batch API, который снижает стоимость обработки больших объемов данных для LLM-задач до 50% за счет асинхронной обработки, что особенно выгодно для задач, не требующих мгновенных ответов, таких как генерация контента или анализ данных.

Расширенный контекст

Создание высококачественных наборов данных для обучения больших языковых моделей (LLM) и других систем искусственного интеллекта является одной из самых сложных нерешенных проблем в машинном обучении. Веб представляет собой крупнейший корпус человеческих знаний, но преобразование необработанного HTML в чистые, структурированные обучающие данные — это то место, где большинство конвейеров обработки данных терпят неудачу. Для решения этой проблемы представлен Web to Markdown/JSON API — сервис, не требующий конфигурации, который преобразует любую веб-страницу в чистый Markdown или структурированный JSON одним HTTP-запросом. Он не требует использования headless-браузеров, сложных регулярных выражений или обхода DOM. В рамках обучающего материала демонстрируется создание полного конвейера для сбора данных ИИ, который сканирует список начальных URL-адресов, извлекает чистый текст в больших масштабах, дедуплицирует и нормализует контент из разных источников, а также выводит данные в форматах, готовых для дообучения (JSONL для OpenAI, Parquet для Hugging Face), соблюдая при этом ограничения по частоте запросов. Кроме того, для пользователей, работающих с большими объемами LLM-задач, таких как генерация контента, обогащение данных, офлайн-оценка или анализ отзывов клиентов, представлен Batch API. Этот API позволяет значительно сократить расходы, отправляя тысячи синхронных запросов API, что является пустой тратой денег и лимитов скорости. Batch API от крупных поставщиков, таких как OpenAI и Anthropic, сокращает расходы на API на 50%, предоставляя при этом значительно более высокие лимиты скорости. Результаты обрабатываются асинхронно в течение 24-часового окна.

Представленные API решают две критически важные проблемы в области искусственного интеллекта: доступность и стоимость создания обучающих данных. Web to Markdown/JSON API демократизирует процесс получения чистых данных из веба, устраняя технические барьеры и позволяя разработчикам сосредоточиться на качестве моделей, а не на сложности парсинга. Batch API, в свою очередь, делает крупномасштабную обработку данных для LLM более доступной, снижая затраты на 50%. Это особенно важно для стартапов и исследователей с ограниченным бюджетом, позволяя им проводить более масштабные эксперименты и быстрее выводить продукты на рынок. Сочетание этих инструментов ускоряет разработку и внедрение ИИ-решений, делая их более эффективными и экономически выгодными.
